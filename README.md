# Olist E-commerce Customer Experience Analysis

## 프로젝트 배경

Olist는 브라질의 중소 판매자와 온라인 마켓플레이스를 연결하는 이커머스 플랫폼입니다. 고객 주문 이후 판매자가 상품을 준비해 물류 파트너에게 인계하고, 물류 파트너가 고객에게 상품을 배송합니다.

배송 지연은 고객 경험과 플랫폼 신뢰도를 저하시킬 가능성이 있지만, 전체 배송시간만으로는 지연이 판매자 처리 단계와 물류 운송 단계 중 어디에서 발생하는지 구분하기 어렵습니다. 또한 지연과 고객 불만이 집중되는 관리 대상이 불분명하면 효과적인 개선 우선순위를 결정하기 어렵습니다.

## 문제 정의

> 배송 지연과 고객 만족도의 관련성을 확인하고, 지연이 집중되는 처리 단계와 관리 대상을 파악하여 Olist의 배송관리 우선순위를 제안합니다.

## 주요 분석 질문

1. 배송 지연 주문에서 저평점 비율이 더 높게 관찰되는가?
2. 배송이 며칠 이상 늦어질 때 저평점률이 크게 증가하는가?
3. 지연은 판매자 처리 단계와 물류 운송 단계 중 어디에서 주로 나타나는가?
4. 어떤 판매자군·상품군·지역에서 배송 지연과 저평점이 함께 집중되는가?

## 핵심 지표

- 배송 지연율
- 평균 지연일
- 저평점률
- 판매자 처리시간
- 물류 운송시간
- 지연·저평점 동시 발생률

## 기대되는 실무 활용

- 관리가 필요한 판매자군 선정 및 출고 SLA 점검
- 지연이 집중되는 물류 구간과 지역 점검
- 실제 배송 성과를 반영한 예정 배송일 조정
- 장기 지연 주문에 대한 고객 사전 안내
- 배송 이외의 원인으로 발생한 저평점 주문의 별도 관리

## 데이터

- **데이터셋:** Brazilian E-Commerce Public Dataset by Olist
- **대상 기간:** 2016–2018년
- **규모:** 약 10만 건의 주문
- **주요 데이터:** 주문, 배송, 판매자, 상품, 고객 리뷰

## 분석 시 유의사항

본 프로젝트는 관찰 데이터를 사용하므로 배송 지연과 저평점 사이의 인과관계를 확정하지 않습니다. 또한 하나의 주문에 여러 상품과 판매자가 포함될 수 있어 주문 단위와 주문상품 단위를 구분하여 분석합니다.
